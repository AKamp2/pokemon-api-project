/api/getAllPokemon

Query Params

  • none - Returns all Pokemon in the database.

Returns

A JSON array of Pokemon objects in the format:

[{"id": "001", "num": "001", "name": "Bulbasaur", "type": ["Grass", "Poison"], ...}]

Examples

Request: /api/getAllPokemon

Result: [{"id": "001", "num": "001", "name": "Bulbasaur", ...}]...

/api/getWeaknesses

Query Params

  • name (string) - The Pokemon's name to search for.

Returns

A JSON object with the Pokemon's weaknesses:

{"weaknesses": ["Fire", "Psychic"]}

Examples

Request: /api/getWeaknesses?name=Bulbasaur

Result: {"weaknesses": ["Fire", "Psychic"]}...

/api/getHeightWeight

Query Params

  • minHeight (number) - Minimum height to filter.
  • maxHeight (number) - Maximum height to filter.
  • minWeight (number) - Minimum weight to filter.
  • maxWeight (number) - Maximum weight to filter.

Returns

A JSON array of Pokemon objects that match the height and weight criteria:

[{"id": "001", "num": "001", "name": "Bulbasaur", "height": "0.7", "weight": "6.9"}, ...]

Examples

Request: /api/getHeightWeight?minHeight=0.5&maxHeight=1.5&minWeight=5&maxWeight=100

Result: [{"id": "001", "num": "001", "name": "Bulbasaur", ...}]...

Invalid Request: /api/getHeightWeight?minHeight=0.5&maxHeight=one&minWeight=5&maxWeight=100

Result: {"message": "All fields must be valid numbers.", "id": "invalidParams"}

/api/getType

Result: [{"id": "001", "num": "001", "name": "Bulbasaur", ...}]...

/api/addPokemon

Supported Body Formats

application/json and application/x-www-form-urlencoded

Body Params

  • name (string) - The name of the Pokemon.
  • num (number) - The Pokedex number of the Pokemon.
  • type (string) - The primary type of the Pokemon. The second type can be left empty.
  • height (number) - The height of the Pokemon in meters.
  • weight (number) - The weight of the Pokemon in kilograms.

Returns

A JSON object with the newly created Pokemon:

{"message": "New Pokemon created successfully!", "newPokemon": {"id": "152", "num": "152", "name": "Chikorita", ...}}

Body Example

{
      "name": "Chikorita",
      "num": 152,
      "type": "Grass",
      "height": 1.2,
      "weight": 12.0
    }

Examples

Request: /api/addPokemon

Body: { "name": "Chikorita", "num": 152, "type": "Grass", "height": 1.2, "weight": 12.0 }

Result: {"message": "New Pokemon created successfully!", "newPokemon": {...}}...

Invalid Request: /api/addPokemon

Body: {"name": "Chikorita", "num": "two", "type": "Grass", "height": "one", "weight": "12.0"}

Result: {"message": "num, height, and weight must all be valid numbers.", "id": "invalidParams"}

/api/addRanking

Supported Body Formats

application/json and application/x-www-form-urlencoded

Body Params

  • name (string) - The name of the Pokemon.
  • ranking (string) - The tier ranking (S, A, B, C, D, F).

Returns

A JSON object indicating success or failure:

{"message": "Ranking added to Bulbasaur."}

Body Example

{
  "id": "001",
  "num": "001",
  "name": "Bulbasaur",
  "type": ["Grass", "Poison"],
  "height": "0.7",
  "weight": "6.9",
  "weaknesses": ["Fire", "Psychic"],
  "ranking": "A"
}

Examples

Request: /api/addRanking

Result: {"message": "Ranking added to Bulbasaur."}...
